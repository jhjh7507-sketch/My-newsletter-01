# 수업 녹음 → 카톡 정리 자동화

트레이너가 수업을 녹음하면 아이폰 단축어가 드라이브에 올린다. 예약 작업이 아래 두 모드로 돈다.
정리 규칙은 `.claude/pt/kakao-style.md`. 이 작업 중에는 git 커밋·푸시를 하지 않는다.

## 드라이브
| 폴더 | ID | 내용 |
|---|---|---|
| 수업녹음 | `126Sol0WoFopiFiDpnS_41K-VfVh_2eXH` | 녹음 m4a. 파일 이름 = 업로드 시각(KST) `yyyy-MM-dd HH-mm.m4a` |
| 카톡정리 | `1-Gxj2AWmHLqGnUty-_D0DhxMvRYetYOT` | 보낼 글. 제목 `YYYY-MM-DD 이름 회원님` |
| 회원기록 | `1o4uTHlS1jEVWOJEplkG5XHe9oHJGtSfG` | 회원별 수업 기록. 제목 `이름 YYYY-MM-DD 기록` |

## 캘린더는 한 번만 조회한다
구글 캘린더는 짧은 시간에 여러 번 부르면 "Resource has been exhausted"(할당량 초과)로 막힌다.
그래서 한 번 실행할 때 캘린더 조회는 아래 한 번뿐이고, 오늘 수업 고르기와 다음 수업 날짜 찾기를 모두 이 결과로 한다.
- `list_events`: 오늘(KST) 00:00 ~ 14일 뒤 00:00, `fullText` "회원님", `orderBy` startTime, `pageSize` 250.
  `nextPageToken`이 있어도 더 부르지 않는다.
- 막히면 한 번만 다시 시도한다. 그래도 막히면 "캘린더 조회 실패(할당량 초과) - 다음 시간에 다시 봅니다" 한 줄만 출력하고 끝낸다.
  이때 "새로 정리할 수업 없음"이라고 쓰지 않는다.
- `search_events`로 바꿔 부르지 않는다 (같은 할당량을 쓴다).

## 모드 A: 매시간 점검 (예약 작업, 매시 30분)
1. 캘린더 결과에서 오늘 일정 중 제목에 "회원님"이 들어간 것을 고른다. 제목 "최윤정회원님" → 이름 "최윤정".
2. 그중 수업 끝 + 10분이 지났고, 카톡정리 폴더에 `YYYY-MM-DD 이름 회원님`이 아직 없는 수업만 고른다.
3. 고른 수업마다 모드 B를 진행한다. 녹음이 없으면 건너뛴다 (다음 시간에 다시 본다).
4. 정리한 게 없으면 "새로 정리할 수업 없음" 한 줄만 출력한다. 있으면 수업마다 카톡 글을 이어서 출력한다.

## 모드 B: 수업 하나 정리
1. 카톡정리 폴더에 `YYYY-MM-DD 이름 회원님`이 이미 있으면 그 내용을 출력하고 끝낸다 (미리보기·다시 정리일 때는 계속 진행).
2. 수업녹음 폴더에서 `createdTime`이 (수업 시작 - 10분) ~ (수업 끝 + 20분)인 파일을 찾는다 (`parentId = '<수업녹음 ID>'`).
   - 없으면 이 수업은 건너뛴다. 수업 끝 + 3시간이 지났는데도 없으면
     "<이름> 회원님 수업 녹음을 못 찾았어요"라고 한 줄 알린다.
3. 파일을 `createdTime` 순으로 `download_file_content`로 받는다. 결과가 커서 파일로 저장되면 그 JSON의
   `content`(base64)를 디코드해 스크래치패드에 `.m4a`로 쓴다.
4. `python3 .claude/pt/stt.py <스크래치패드>/class <파일들...>` 로 글로 바꾸고 결과 txt를 전부 읽는다.
5. 맥락을 모은다.
   - 회원기록 폴더에서 제목에 이름이 들어간 기록 중 이 수업 날짜 것을 빼고 최근 2개를 읽는다 (지난 무게·이슈와 비교할 거리).
     1개뿐이면 1개, 없으면 건너뛴다.
   - 다음 수업 날짜는 캘린더 결과에서 이 수업 다음에 오는 "이름회원님" 일정으로 정한다. 캘린더를 따로 부르지 않는다.
     2주 안에 없으면 날짜를 쓰지 않고 "다음 수업 때 뵙겠습니다 회원님!"으로 맺고 `[확인: 다음 수업 날짜]`를 남긴다.
6. `kakao-style.md` 규칙대로 카톡 글을 쓴다. 녹음 속 이름이 음성인식으로 틀려도 캘린더 이름을 쓴다.
   운동 이름·무게가 녹음에서 확실치 않으면 그 자리를 `[확인: ...]`으로 남긴다.
7. 저장한다 (미리보기면 건너뛴다).
   - 카톡정리 폴더: 제목 `YYYY-MM-DD 이름 회원님`, 내용 = 카톡 글 (text/plain).
   - 회원기록 폴더: 제목 `이름 YYYY-MM-DD 기록`, 내용 = 루틴(운동·무게·개수·세트)과 다음 수업 비교용 메모
     (통증, 컨디션, 고친 자세, 무게 이야기).
   - 다시 정리라서 같은 제목 문서가 이미 있으면 새 문서를 만든 뒤 예전 문서는 `trash_file`로 휴지통에 보낸다
     (드라이브 도구로는 문서 내용을 고쳐 쓸 수 없다. 휴지통에서 30일 동안 되살릴 수 있다).
8. 카톡 글을 그대로 출력한다 (앞에 `▶ 이름 회원님` 한 줄, `[확인: ...]`이 있으면 끝에 한 줄로 알린다).

## 직접 부를 때
- "드라이브 확인해줘": 모드 A를 지금 바로 한 번 돌린다.
- "미리보기로 확인해줘": 모드 A를 돌리되, 이미 정리된 수업도 다시 정리하고 드라이브에는 아무것도 저장하지 않는다
  (카톡정리·회원기록 둘 다). 결과는 출력만 한다. 날짜를 말하면(예: "10/26 미리보기") 그날을 오늘로 본다.
- "○○ 회원님 다시 정리해줘": 캘린더를 한 번 조회한 뒤 그 수업만 모드 B를 다시 하고 저장한다 (7단계의 예전 문서 처리대로).
