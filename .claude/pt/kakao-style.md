# 수업 정리 카톡 규칙

수업 녹음(드라이브 `수업녹음` 폴더) → 운동 루틴 + 피드백 정리 → 트레이너가 카톡으로 복사해 보냄.

## 구성 (없는 항목은 뺀다)
1. 날짜·부위 한 줄 (예: `10/26(월) 등 운동`)
2. 루틴 먼저, 운동 순서대로 한 줄씩
   - 세트마다 무게가 다르면: `로우로우 1세트 15kg 20개 / 2세트 17.5kg 20개 / 3세트 20kg 20개`
   - 무게가 같으면: `랫풀다운 15kg 20개 3세트`
3. 루틴 다 적은 뒤 운동별 피드백 `[운동이름]` 아래 3~4줄
4. 숙제 (스트레칭, 식단, 홈트 이야기가 나왔을 때만)
5. 응원 한마디 1~2줄

## 말투
- 회원 호칭은 "회원님". 존댓말, 밝게 ("넵", "~해주기", "~해봐요").
- 이모지는 쓰지 않는다.
- 피드백은 "~해야 ~됩니다!" 꼴로 이유와 결과를 같이: "어깨를 젖힌 상태로 내려와야 어깨에서 소리가 나지 않습니다!" 트레이너가 이유를 말하지 않은 큐는 이유를 지어내지 말고 "~해주세요!"로.
- 문장은 끝까지 맺는다 (명사형 "~하기"로 끊지 않기).
- 표현: "팔꿈치~손" 대신 "팔꿈치부터 손이".
- 마무리는 트레이너 카톡 말투: "~감사합니다!", "다음 주 월요일날 뵙겠습니다 회원님!" 다음 수업 날짜는 구글 캘린더에서 "○○○회원님" 일정으로 찾는다.
- 길이: 피드백은 운동당 3~4문장. 핵심 큐 + 왜 그런지 한 줄. 확인 질문("~찾으셨죠?")은 뺀다.

## 넣을 것 / 뺄 것
- 넣기: 세트 사이·끝난 뒤 피드백, 운동과 관련된 대화(통증, 지난 운동, 컨디션).
- 빼기: 운동과 무관한 잡담, 다른 회원 이야기, 녹음 자체에 대한 이야기, 이미 회원과 나눈 병원·진단 이야기.
- 말로 확인 안 된 무게·횟수는 지어내지 않는다. 모르면 트레이너에게 묻는다.

## 녹음 읽는 법
- 첫머리(또는 끝)에 "○○ 회원님"이라고 말함. 이름은 음성인식이 자주 틀리므로 캘린더·카톡 이름과 맞춘다.
- 횟수는 트레이너가 소리 내서 셈. 목표는 대부분 20개. 코멘트하다 숫자가 조금 어긋나도 20/15/12/10개 중 가까운 값으로 고정해서 적는다.
- 운동이 바뀔 때 "로우로우 갈게요, 15킬로"처럼 이름과 무게를 말해 달라고 안내함. 안 들리면 앞뒤 맥락으로 추정하고 확인 질문.
