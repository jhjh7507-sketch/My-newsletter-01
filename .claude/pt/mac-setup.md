# 맥북 설정: 녹음 자동 업로드 + 카톡 자동 전송

맥에서 연 Claude Code 세션이 이 문서를 읽고 설정한다. 단계마다 직접 실행해서 되는 걸 확인한 뒤 넘어간다.

## 전체 흐름
1. 아이폰·아이패드 음성 메모로 녹음 → iCloud → 맥 음성 메모 폴더에 파일로 들어온다.
2. **맥 (upload)**: 새 녹음을 무료 Whisper로 받아쓴 뒤, 받아쓴 글(.txt)과 녹음(.m4a)을 구글 드라이브 데스크톱의 `수업녹음` 폴더로 복사 → 드라이브에 올라간다.
3. **클라우드 예약 작업** (매시 30분, `run.md` 모드 A): 받아쓴 글 → 카톡 글 → `카톡정리/YYYY-MM-DD 이름 회원님.txt`
4. **맥 (send)**: `카톡정리`에 새 `.txt`가 생기면 카카오톡으로 그 회원에게 보내고 `카톡정리/보냄/`으로 옮긴다.

스크립트는 `.claude/pt/mac/`에 둔다. 회원 이름·카톡방 표, 로그, 설정은 개인정보라 저장소가 아니라 `~/.pt/`에만 둔다.

## 0. 트레이너가 직접 할 것
- 아이폰·아이패드·맥 모두: 설정 → Apple 계정 → iCloud → **음성 메모** 켜기
- 맥: **Google Drive 데스크톱** 설치, jhjh7507 계정 로그인. Finder에 `내 드라이브/수업녹음`, `내 드라이브/카톡정리`가
  보이는지 확인. 스트리밍 모드면 `카톡정리` 폴더는 "오프라인에서 사용 가능"으로 둔다.
- 맥: **카카오톡** 로그인, 자동 로그인 켜기.
- 맥: 전원 연결 시 **잠자기 안 함** (시스템 설정 → 배터리 또는 에너지). 맥이 자거나 꺼져 있으면 업로드·전송이 멈추고, 켜지면 밀린 것을 처리한다.

## 1. 녹음 → 드라이브 (`.claude/pt/mac/upload.py`)
- 음성 메모 파일 위치: `~/Library/Group Containers/group.com.apple.VoiceMemos.shared/Recordings/`
  (macOS 버전에 따라 다를 수 있으니 실제 위치를 찾는다). 읽으려면 실행하는 프로그램에 **전체 디스크 접근 권한**이 필요하다.
- 아직 안 올린 녹음 중 iCloud 다운로드가 끝난 것(1분 동안 크기가 안 변한 것)만 처리한다.
- `.m4a`가 아니면(`.qta` 등) `afconvert`나 ffmpeg로 m4a로 바꾼다. 클라우드는 오디오(m4a)만 찾는다.
- 받아쓰기: 무료 Whisper를 맥에 설치해 한국어로 받아쓴다 (애플 실리콘이면 `mlx-whisper`의 large-v3-turbo, 아니면 `whisper.cpp`).
  - 결과 형식은 클라우드의 `stt.py`와 같게: 20초 안팎마다 한 줄 `[mm:ss] 말한 내용`, 맨 위에 `===== 1: <파일 이름> =====`.
  - 헬스장 음악·소음 구간에서 없는 말을 지어내거나 같은 문장을 반복할 수 있다. 말소리 구간만 넣는 VAD 옵션을 켜고,
    같은 줄이 연달아 반복되면 지운다.
  - 처음 설치하면 드라이브 `수업녹음`의 `논현동.m4a`(57분), `논현동 2.m4a`(41분)로 시험한다. 같은 녹음을 ElevenLabs로 받아쓴 글과
    비교해 운동 이름·무게·횟수를 얼마나 맞히는지 트레이너에게 보여 준다. 걸린 시간도 알린다.
- 받아쓴 글을 먼저 `yyyy-MM-dd HH-mm-ss <음성 메모 제목>.txt`로, 그다음 녹음을 같은 이름의 `.m4a`로 드라이브 `수업녹음` 폴더에 복사한다.
  받아쓰기가 실패하면 녹음만 올린다 (클라우드가 2시간 뒤 ElevenLabs로 대신 변환한다).
- 올린 파일은 `~/.pt/uploaded.txt`에 적어 두 번 올리지 않는다. 처음 설치할 때는 이미 있는 옛 녹음을 올리지 말고 목록에만 적는다.
- launchd(`~/Library/LaunchAgents/`)로 5분마다 실행.
- 확인: 1분짜리 녹음 → 몇 분 뒤 드라이브 `수업녹음`에 `.txt`와 `.m4a`가 올라오는지.

## 2. 카톡정리 → 카톡 (`.claude/pt/mac/send.py`)
- 드라이브 `카톡정리` 폴더(로컬 경로)의 새 `.txt`만 본다 (`보냄/` 안은 보지 않는다).
- 파일 이름 `YYYY-MM-DD 이름 회원님.txt`에서 이름을 읽고 `~/.pt/kakao-names.tsv`(이름 ⇥ 카톡 채팅방 이름, 트레이너가 채움)에서
  채팅방을 찾는다. 표에 없거나 같은 이름이 둘이면 보내지 않고 맥 알림으로 알린다.
- 보내기 전 검사: 글이 499자 이하인지, `[확인`이 없는지, 파일 날짜가 오늘·어제인지. 하나라도 걸리면 보내지 않고 알린다.
- 카카오톡을 AppleScript(System Events)로 조작: 채팅방 검색 → 열기 → 클립보드로 붙여넣기 → 전송.
  실행하는 프로그램에 **손쉬운 사용** 권한이 필요하다. 보낸 뒤 원래 클립보드를 되돌린다.
- 보낸 파일은 `카톡정리/보냄/`으로 옮기고 `~/.pt/sent.log`에 시각·이름·채팅방을 적는다.
- `~/.pt/config`의 `TEST_MODE=1`이면 회원 대신 **나와의 채팅**으로 보낸다. 처음 설치는 1로 두고,
  트레이너가 몇 번 확인한 뒤 0으로 바꾼다.
- launchd로 5분마다, 07~24시에만 실행.

## 3. 확인 순서
1. 1분 녹음 → 드라이브 `수업녹음`에 올라오는지.
2. 클라우드 세션에 "드라이브 확인해줘" (또는 매시 30분 자동) → `카톡정리`에 `.txt`가 생기는지.
3. 맥이 나와의 채팅으로 보내는지 → 괜찮으면 `TEST_MODE=0`.

## 주의
- 카카오톡 자동 조작은 카카오 정책상 제한될 수 있다. 하루 몇 건(수업 수만큼)만 보낸다.
- 카카오톡 앱이 업데이트되면 화면 구성이 바뀌어 전송이 깨질 수 있다. 실패하면 보내지 않고 알림만 남긴다.
